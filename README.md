# Milk, made in Australia

Interactive Australian dairy story by Senuth Dias for FIT3179 Data Visualisation 2. Revised 22 October 2026; data checked 13 October 2026.

## View and publish
Static website: enable GitHub Pages from main and /(root). The repository root must contain index.html, styles.css, app.js, data/, specs/ and assets/. No build or package installation is needed. Three pinned Vega libraries load from jsDelivr, requiring internet access. For local preview run `python3 -m http.server 8765` here and open http://localhost:8765/. Direct file opening can block chart data loading.

## Charts and interaction
Thirteen views use original readable Vega/Vega-Lite specs 01–13. Three distinct maps show production volume, relative change and export relationships. Other views cover the annual trend, seasonal monthly shares, additive state change, registered-farm endpoints, separate state ratio slopes, labelled state-share matrix, raw-milk allocations, ABS relative purchase trends, selected-type waffles and ranked export-value bars. Every view was revised for intuitive reading on 21 October. Direct labels reduce dependence on hover and colour. Six slope panels share one scale. The full-width export map always displays all ten connections. A shared radial fan separates the paths without crossings beyond the common Australian origin. Desktop callouts name the countries; compact phone callouts use numbers matched to the full market list. Hover or selection highlights a route without hiding the others. White halos separate nearby strokes. Dashed guides locate the labels; curves are schematic relationships, not shipping routes.

Eleven native dropdowns support local comparisons and preserve selections on resize. Waffles default to regular milk against a grey remainder; a selected category starts at the top left in both panels, with an optional All types mix. Largest-remainder rounding produces exactly 100 cells per panel while labels/tooltips retain exact shares and reported million litres. State outlines offer All; the map offers Overview. Native dropdowns retain keyboard access. Four question links introduce the chapters.

Conservative inventory: 13 views, 11 distinct construction families, 9 advanced families, three map types. Repeated lines and heatmaps count once. Slope panels and waffle pairs each count once. Basic lines and ranked bars fit their questions; an advanced label alone does not establish effective use or assessment credit.

## Sources and interpretation
Substantive sources are Dairy Australia’s production statistics and Australian Dairy Industry In Focus 2025, plus ABS Apparent Consumption of Selected Foodstuffs, Australia, 2023–24. Full source links, coverage and caveats are on the webpage. Geometry comes from ABS ASGS 2021 and Natural Earth via Vega Datasets. Fraunces includes its SIL Open Font License.

Production uses the revised 2020–21 to 2025–26 series; structure preserves the annual-report vintage. Monthly shares sum to 100% within region/year, with the peak month outlined. Farm endpoints default to an index (2011–12 = 100), with a switch to raw counts. Indexed counts are not surviving-farm cohorts; dot labels give actual farms. Slope headers show relative changes; the ABS key updates for the selected end year. Waffles print selected-type ML separately from total sales. Farm ratios use rounded March cows and annual farm counts, not individual-farm measurements. ABS measures retail purchases, not diet. Its lines use percentage changes from separate 2018–19 quantities; equal relative changes do not mean equal grams. Waffles show composition, with total sales printed separately (2,314 ML in 2010–11; 2,340 ML in 2024–25). Nominal export dollars are distinct from product tonnes. Geographic links are schematic relationships, not routes. Greater China is the published aggregate. ACT/NT lack separate observations and are not zero.
